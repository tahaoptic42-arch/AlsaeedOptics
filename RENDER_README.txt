Render deployment starter

This project is a test/demo deployment package.
1. Upload the contents of this folder to a GitHub repository.
2. In Render choose New > Blueprint and connect that repository, or create a Web Service.
3. For a Web Service use Build Command: pip install -r requirements.txt
   and Start Command: gunicorn app:app
4. Set SHOP_WHATSAPP to the shop's real WhatsApp number in international digits.
5. SECRET_KEY is generated by the included render.yaml Blueprint.

IMPORTANT DATA WARNING:
The current app uses SQLite and stores uploaded images on its local filesystem.
Render Free services have ephemeral storage; product changes, SQLite data and uploaded
images can be lost when the service restarts, spins down, or redeploys. Do not use this
as a permanent live shop until its database and image uploads are moved to durable storage.
Render Free web services also sleep after 15 minutes without traffic and can take about
a minute to wake. Use an adult/guardian's help for account/payment or public business setup.
